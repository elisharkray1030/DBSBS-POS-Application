# 01 — Startup script and dependency management

**What to build:** A double-click startup script that becomes the app's entry point. On first run it checks whether the `customtkinter` dependency is installed; if not, it installs it via pip, then launches the application. When the dependency is already present it launches straight through. If the dependency is missing and pip cannot reach the network, it shows a clear error telling the organizer to run the script once with internet first. The project's run instructions are updated to point at the new entry point.

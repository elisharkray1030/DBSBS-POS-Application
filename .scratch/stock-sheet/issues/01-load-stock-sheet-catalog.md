# 01 — Load the organizer's Stock sheet as the catalog

**What to build:** Loading the organizer's Stock sheet CSV (columns `ItemID, ItemName, Price, Inventory, Sales, Revenue`) through the session facade creates the catalog. Each item carries its Item ID as its identity; `Inventory` becomes the item's starting quantity, with a blank value meaning sell-by-demand (no starting quantity); pre-filled `Sales`/`Revenue` values in the loaded file are ignored. The old `Name, Price, Quantity` format is no longer accepted, and a file with the wrong header, a missing or duplicate Item ID, or an unparseable price is rejected with a clear error. The item list reports each item's Item ID alongside its name, price, and starting quantity, and the catalog (including Item IDs) survives reopening the device's store.

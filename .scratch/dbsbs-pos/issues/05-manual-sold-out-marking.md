# 05 — Manual sold-out marking

**What to build:** The cashier can mark an item sold-out on their device when the stall physically runs out. The item dims in the list and can no longer be added to a new sale. The mark is per-device — the app never infers sold-out from the shared stockpile, because the two laptops have no network between them.

**Blocked by:** 02 — Build & settle a cash sale

**Status:** ready-for-agent

- [ ] A cashier can mark an item sold-out on their device
- [ ] A sold-out item is dimmed in the item list
- [ ] A sold-out item cannot be added to a new sale
- [ ] The sold-out mark is per-device and never affects the other laptop

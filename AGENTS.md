# Agent instructions for DBSBS-POS-Application

Offline POS Application for DBS Garden Fete.

## Agent skills

### Issue tracker

Tickets and issues live as GitHub issues in this repo's GitHub repository;
feature specs are published to the tracker as GitHub issues too (there is no
local `.scratch/` anymore). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles map to the labels `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
